# Practical 08 – Backup and Restore

## Aim

To understand how to create file backups and restore deleted files using Linux file management commands.

---

## Problem Statement

### Task 8: Backup and Restore

**Objective:** Create backups and restore files using the `cp` command.

### Instructions

1. Create a directory called `linux_task6`.
2. Create a file called `important.txt`.
3. Add at least 10 lines of content.
4. Create a directory called `backup`.
5. Copy `important.txt` into `backup`.
6. Rename the backup as `important_backup.txt`.
7. Delete the original `important.txt`.
8. Copy the backup back to the main directory.
9. Rename it to `important_restored.txt`.
10. Display its contents.

---

## Overview

Creating backups is an essential practice in file management to prevent data loss. Linux provides commands that make it easy to copy, rename, delete, and restore files. This practical demonstrates the complete backup and restoration process using terminal commands while ensuring that the original file can be recovered successfully.
