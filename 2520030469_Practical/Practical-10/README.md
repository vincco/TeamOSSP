# Practical 10 – Mini Linux Administration Challenge

## Aim

To perform and understand Linux file administration by organizing project files, managing directories, modifying file permissions, creating backups, and maintaining a structured project using Linux terminal commands.

---

## Problem Statement

### Task 10: Mini Linux Administration Challenge

**Objective:** Perform a real-world Linux file administration exercise.

Imagine you are managing a project called `student_portal`.

Create the following directory structure:

```text
student_portal/
├── src/
├── docs/
├── backup/
├── logs/
└── config/
```

### Instructions

1. Create all the required directories.
2. Create the following files:
   - `main.c`
   - `student.c`
   - `README.txt`
   - `config.txt`
   - `system.log`
3. Move the C files into the `src` directory.
4. Move `README.txt` into the `docs` directory.
5. Move `config.txt` into the `config` directory.
6. Move `system.log` into the `logs` directory.
7. Add at least 15 lines to `system.log`.
8. Display the first five lines of `system.log`.
9. Display the last five lines of `system.log`.
10. Copy `README.txt` to the `backup` directory.
11. Rename the copied file as `README_backup.txt`.
12. Change the permission of `config.txt` to `600`.
13. Change the permission of `README.txt` to `644`.
14. Delete `README_backup.txt`.
15. Remove the empty `backup` directory.
16. Display the final directory structure using `ls -R`.

---

## Overview

Linux system administration involves organizing project files, managing directories, controlling file permissions, maintaining backups, and verifying project structures. This practical integrates these essential administrative tasks into a single workflow, demonstrating how Linux commands can be used to efficiently manage and maintain a structured project environment.
