# Practical 04 – Organize Files

## Aim

To understand how to organize files into different directories by moving and renaming them using Linux terminal commands.

---

## Problem Statement

### Task 4: Organize Files

**Objective:** Organize files into different directories using the `mv` command.

### Instructions

Start with the following structure:

```text
organization/
├── file1.txt
├── file2.txt
├── file3.txt
├── image1.jpg
└── image2.jpg
```

Then:

1. Create a `documents` directory.
2. Create an `images` directory.
3. Move all `.txt` files into `documents`.
4. Move all `.jpg` files into `images`.
5. List the contents of each directory.
6. Rename `file1.txt` to `notes.txt`.
7. Rename `image1.jpg` to `photo.jpg`.

---

## Overview

Organizing files into appropriate directories is an essential aspect of file management in Linux. The `mv` command is used not only to move files between directories but also to rename files. This practical demonstrates how files can be systematically organized and renamed to improve directory structure and file management.
