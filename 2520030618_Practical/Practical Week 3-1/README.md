# Week 3-1 Practical – Process Creation and Process Synchronization

## Aim

To perform and understand process creation and synchronization in Linux using the `fork()`, `sleep()`, and `wait()` system calls.

---

## Programs

1. sleep.c
2. forksleep.c
3. waitfork.c

---

## Overview

This practical demonstrates the basic concepts of process management in Linux. It explains how a child process is created using `fork()`, how execution can be delayed using `sleep()`, and how a parent process can synchronize with a child process using `wait()`. These concepts are fundamental to operating system process management.
