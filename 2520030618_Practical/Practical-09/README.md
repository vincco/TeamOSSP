# Practical 09 – Complete Linux File Management Challenge

## Aim

To apply Linux file management commands by creating directories, organizing files, managing permissions, and performing file operations in a single practical exercise.

---

## Problem Statement

### Task 9: Complete Linux File Management Challenge

**Objective:** Use multiple Linux file management commands together to perform a complete file management workflow.

### Instructions

1. Create a directory called `linux_project`.
2. Create the following directories:
   - `source`
   - `backup`
   - `docs`
3. Create the following files inside `source`:
   - `main.c`
   - `helper.c`
   - `README.txt`
4. Add at least 20 lines to `README.txt`.
5. Display the first 5 lines.
6. Display the last 5 lines.
7. Copy `main.c` to the `backup` directory.
8. Copy `README.txt` to the `docs` directory.
9. Rename `helper.c` to `functions.c`.
10. Change the permission of `README.txt` to `644`.
11. Delete the copied `main.c` from `backup`.
12. Remove the empty `backup` directory.
13. Display the final directory structure.

---

## Overview

Linux provides a wide range of commands for efficiently managing files and directories. This practical combines file creation, copying, moving, renaming, permission management, and directory operations into a single workflow. It demonstrates how different Linux commands work together to organize and maintain project files in a structured manner.
