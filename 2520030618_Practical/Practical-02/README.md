# Practical 02 – Copy and Move Files

## Aim

To understand the Linux file management commands used for copying, moving, and renaming files and directories through the terminal.

---

## Problem Statement

### Task 2: Copy and Move Files

**Objective:** Practice copying, moving, and renaming files.

### Instructions

1. Create a directory called `linux_task2`.
2. Create three files:
   - `source.txt`
   - `data.txt`
   - `notes.txt`
3. Add some content to `source.txt`.
4. Create a directory called `backup`.
5. Copy `source.txt` into `backup`.
6. Copy `data.txt` into `backup` and rename it as `data_backup.txt`.
7. Move `notes.txt` into `backup`.
8. Rename `source.txt` to `original.txt`.
9. Display the final directory structure.

---

## Overview

Linux provides efficient commands for managing files without the need for graphical interfaces. This practical demonstrates how to copy files, move files between directories, rename files, and organize directory structures using terminal commands. These operations are commonly used for file organization, backup creation, and project management in Linux systems.
