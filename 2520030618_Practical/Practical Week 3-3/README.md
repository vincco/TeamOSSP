# Week 3 – Process State Transitions

## Aim

To study process creation in Linux using the `fork()` system call and observe the relationship between parent and child processes.

## Description

This program creates a child process using `fork()`. It displays the Process ID (PID) of both the parent and child processes, displays the Parent Process ID (PPID) of the child process, demonstrates process synchronization using `wait()`, and uses `sleep()` to observe the execution of the child process.
